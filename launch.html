Built for real work

Complex maps.
Simple controls.

Simple Mindmap keeps the interface quiet while giving you the tools needed to organise large policy libraries, HRIS models, processes, research and project knowledge.

01↔

True canvas navigation

Drag to pan, zoom around the pointer, fit the entire map to screen or centre any selected node instantly.

02✣

Two-sided thinking

Move primary branches to either side of the centre node for a balanced radial, snowflake-style layout.

03▤

Multiple maps, one workspace

Keep independent maps open in persistent tabs, rename them and return to the same workspace after a reload.

04↶

Undo with confidence

Every structural change is recorded in session history. Use the Undo button or Ctrl+Z to step back safely.

05◎

Read-only interactive sharing

Export one standalone HTML snapshot that recipients can pan, zoom and explore without changing the source map.

06⇄

Open formats

Import Markdown, export Markdown, create JSON backups and produce clean PDF documents from the same map.

Privacy by architecture

Your ideas never need to leave your device.

The browser edition stores maps locally. The Windows edition writes files to the folder you choose. Simple Mindmap has no backend, no account system and no analytics service.

No server dependencyOpen the HTML file and work completely offline.
